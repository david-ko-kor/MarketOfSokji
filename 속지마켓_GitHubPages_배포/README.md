# 속지마켓 — GitHub Pages 시연판

index.html과 하위 폴더를 저장소 최상위에 올린 뒤 Settings → Pages → Deploy from a branch → main / (root) → Save로 게시합니다.

상세 절차는 [업로드와실행순서.md](업로드와실행순서.md)를 읽으세요.

공용 DB가 없는 브라우저 저장 방식의 교육용 시제품입니다. 실제 다중 사용자 거래·송금·서버 인증을 제공하지 않습니다. 상품 사진 12개는 AI 생성 예시입니다. 원본 코드와 학습·개발 문서는 별도 VS Code 최종 묶음에 있습니다.
